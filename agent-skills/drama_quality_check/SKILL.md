# 分镜连贯性质检 Agent 技能

本技能服务于**分镜连贯性质检** Agent（`drama_quality_check`），负责检查和修复短剧分镜提示词的剧情连贯性。

## 流水线位置

| 方向 | 说明 |
|------|------|
| **上游** | 已生成的图片/视频分镜提示词 |
| **本步产出** | 修复后的分镜提示词 + 质检报告 |
| **下游** | 图片/视频生成 |

## 五大核心检查维度

### 1. 视觉承上启下
- 每个镜头的开头画面必须自然承接上一镜头的结尾状态
- 人物位置、动作、情绪、服装、道具必须前后一致
- 禁止突兀的场景/人物/时间跳跃

### 2. 角色绝对一致
- 同一角色在连贯镜头中外貌、服装、发型、年龄必须保持一致
- 角色受伤状态、情绪变化需有合理过渡
- 角色出场/退场必须有明确的视觉交代

### 3. 场景空间连贯
- 场景转换必须有逻辑：人物移动、镜头切换需合理
- 同一场景内光线方向、时间、色调保持一致
- 道具的出现/消失必须符合剧情逻辑

### 4. 情绪动作连贯
- 角色情绪、动作姿态在连续镜头中要有自然过渡
- 禁止无理由的情绪突变（如上一秒微笑下一秒暴怒）
- 肢体语言需与对话内容匹配

### 5. 画面/运镜完整性
- **图片提示词**：必须包含景别+主体人物+动作表情+环境+光线+色调，80-150字纯中文
- **视频提示词**：必须包含起始画面→镜头运动→结束画面，起始画面必须承接上一镜头

## 质检输出规范

### 检查报告格式
```json
{
  "report": [
    {
      "shotId": "分镜ID",
      "shotNumber": 镜头号,
      "issues": ["具体问题描述"],
      "severity": "error|warning|ok",
      "fixedPrompt": "修正后的完整提示词"
    }
  ]
}
```

### 修复规则
- 原提示词质量合格且连贯 → 返回原提示词，不强行修改
- 原提示词缺失 → 根据剧本描述和前后镜头生成符合剧情的提示词
- 原提示词不连贯 → 修复后保持与前后镜头的衔接
- 修复后的提示词必须是纯中文，80-200字，不含JSON/markdown标记

## 特别注意事项

1. 第一镜头要建立场景和人物关系，给观众明确的空间感
2. 有对白的镜头必须体现说话者的表情/口型/肢体语言
3. 动作镜头要凝固最有张力的瞬间，不能模糊
4. 严禁在提示词中出现：JSON代码、markdown标记、英文单词堆砌、"提示词"字样
5. 批次处理时确保跨批次的衔接性

## 视频分镜特殊规则

- `startFrame` 必须是上一镜头 `endFrame` 的自然延续
- 镜头运动描述（推/拉/摇/移/跟）必须有明确的起始和结束状态
- 对话场景需描述说话者口型变化和听话者反应
