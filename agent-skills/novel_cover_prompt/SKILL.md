# 小说封面提示词

目标：根据书名、作者名、题材和平台，生成一眼能传达类型、氛围和卖点的封面提示词。

## 输入信息

- 书名、作者名
- 题材/频道/平台
- 主角身份、核心冲突、情绪基调
- 目标尺寸或平台要求（如 2:3、3:4、600x800）
- 是否需要文字上图；如果模型文字能力不稳定，应建议后期排版标题。

## 生成原则

- **先传达题材**：玄幻、都市、悬疑、古言、现言、末世、甜宠等视觉符号要清晰。
- **再传达情绪**：爽、燃、冷、甜、虐、悬疑、压迫、治愈。
- **构图可落地**：主体、背景、光影、色彩、标题区域、作者名区域明确。
- **避免版权风险**：不使用具体影视明星、知名 IP、在世艺术家风格名作为要求。
- **平台适配**：移动端封面小图可读，标题区域不要被复杂背景吞掉。

## 输出格式

- 封面方向说明
- 主 prompt（中文）
- 可选英文 prompt
- negative prompt
- 尺寸/构图建议
- 标题排版建议

## 动作/武侠封面增强

当封面题材是武侠、玄幻、修真、格斗、动作短剧或机甲近战时：

- 主体姿态优先选择“运动前一瞬”或“收势余波”，不要只写正面站立。
- 强化武器/法相/拳势/衣袂/环境轨迹线，形成一眼可见的动作类型。
- 画面要有清晰赌注或关系张力：对峙、守护、追杀、独战群敌、败而生敬。
- 避免血腥、致命命中、具体 IP 角色名；用通用类型气质表达相似氛围。
- 标题区域避开刀光、拳势、脸部和高亮特效，保证小图可读。
