# 小说拆文与对标分析

目标：把对标作品拆成可学习的功能模块，服务原创，不复刻具体内容。

## 使用场景

- 用户要求「拆这本书」「分析黄金三章」「看看这个开头为什么能留人」。
- 用户提供小说文本、章节摘要、书名平台或样章。
- 写作前需要对标人物功能、节奏密度、爽点安排和章末钩子。

## 拆解维度

1. **黄金三章**：首章承诺、主角处境、核心冲突、读者期待、首次爽点/痛点、章末钩子。
2. **角色功能位**：主角、对手、盟友、导师、催化剂、情绪拉扯对象、反转触发器。
3. **情绪曲线**：压迫、误判、反击、释放、悬念、暧昧、失落、震撼等节点如何排列。
4. **节奏模块**：开篇钩子、冲突升级、信息投放、伏笔埋收、爽点兑现、余波延迟。
5. **可迁移规则**：只输出功能、节奏和方法，不复制原文桥段、人设组合或专有设定。

## 输出格式

- 作品/样本边界
- 黄金三章留人机制
- 人物功能位表
- 情绪与爽点节奏表
- 可学习模块
- 不可照搬内容
- 对本项目/新书的改写建议
