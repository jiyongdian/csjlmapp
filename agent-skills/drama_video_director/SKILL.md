# 创世纪 · 视频分镜提示词 Agent 技能

本技能服务于 **视频分镜提示词生成** Agent（`drama_video_director`），将剧本场景原文转化为结构化的视频生成提示词，包含起始画面、结束画面、运镜描述、对白集成和连贯性保证。

## 流水线位置

| 方向 | 说明 |
|------|------|
| **上游** | 剧本场景原文 + 角色/场景/物品资产数据 + 前一分镜状态 |
| **本步产出** | 结构化视频提示词（startFrame, endFrame, prompt, cameraMovement, characterAction, stateNote） |
| **下游** | AI视频生成、人工审片 |

## 核心目标

1. **忠实还原剧本原文**：所有视频提示词必须基于剧本场景描述，不得脱离原文
2. **必须包含对白**：有对白时，prompt 中必须包含角色台词（格式：角色名："台词"）
3. **保证分镜连贯性**：startFrame 必须承接上一分镜的 endFrame，形成无缝衔接
4. **结构化输出**：严格按照 JSON 格式输出，每个字段有明确职责

## 剧本原文解析规则

剧本场景原文的每个部分都需要转化为视频提示词的对应字段：

| 剧本原文元素 | 视频提示词字段 |
|-------------|---------------|
| 【场景N】标题 | startFrame / endFrame 的场景定位 |
| 场景描述 | stateNote（场景氛围、环境说明） |
| 动作描写 | characterAction（角色动作过程） |
| [对白] | prompt 中必须包含对白原文和说话者动作 |
| [承上启下] | startFrame 必须体现承接关系 |
| [镜头指示] | cameraMovement（运镜方式） |

## 字段职责与格式

### prompt（主提示词）
- **必须包含**：完整的视频描述，涵盖起始画面→动作过程→结束画面
- **必须包含对白**：当剧本有对白时，格式为 `角色名（表情/语气）："台词原文"`
- **必须自包含**：不依赖其他字段即可理解完整视频内容
- 80-200字，纯中文

### startFrame（起始画面）
- 描述视频第一帧的静态画面
- **必须承接上一分镜的 endFrame**（若存在）
- 包含：角色位置、姿态、场景初始状态

### endFrame（结束画面）
- 描述视频最后一帧的静态画面
- 必须为下一分镜的 startFrame 做铺垫
- 包含：角色结束姿态、场景结束状态

### cameraMovement（运镜）
- 描述镜头运动方式：推/拉/摇/移/跟/升降/固定
- 必须明确起始和结束的镜头位置
- 示例："从中景缓慢推进至面部特写"

### characterAction（角色动作）
- 描述角色在视频中的完整动作过程
- 有对白时必须包含说话时的口型、表情、手势
- 示例："纪凡赛尔瞪大双眼，瞳孔中蓝光闪烁，身体僵硬，双手微微颤抖"

### stateNote（状态备注）
- 描述场景氛围、光线、情绪基调
- 用于补充其他字段未覆盖的信息

## 对白集成规则（关键）

当剧本包含对白时，**必须在以下字段中体现**：

1. **prompt 字段**：必须包含 `角色名（语气/表情）："台词原文"`
2. **characterAction 字段**：必须描述说话者的口型、表情变化、手势
3. **startFrame / endFrame**：必须体现角色对话时的站位关系

### 对白格式示例

正确格式：
```
雷公（愤怒咆哮）："哪来的野小子，敢动老子的法宝！"
```

错误格式：
- 只写台词不加角色名
- 改写台词内容
- 用英文转述台词

## 分镜连贯性规则（关键）

### 承接规则

| 当前分镜 | 连贯性要求 |
|---------|-----------|
| 第一个分镜 | startFrame 建立场景和人物位置 |
| 后续分镜 | startFrame = 上一分镜 endFrame 的状态延续 |

### 连贯性检查清单

- [ ] startFrame 中的角色位置 = 上一分镜 endFrame 的结束位置（或有合理移动说明）
- [ ] 同一角色外貌/服装/发型跨分镜一致
- [ ] 场景光线/色调/地标跨分镜一致
- [ ] 情绪变化有自然过渡
- [ ] 道具连续（上镜出现的道具本镜必须存在）
- [ ] 下一分镜的 startFrame 已为当前分镜 endFrame 做好铺垫

## 输出格式

### JSON 输出结构

```json
{
  "startFrame": "起始画面描述，角色名+位置+姿态+场景",
  "endFrame": "结束画面描述，角色名+结束姿态+场景",
  "prompt": "完整视频描述，必须包含对白（如有），起始→过程→结束",
  "cameraMovement": "运镜方式描述",
  "characterAction": "角色完整动作过程，含对白时的口型表情",
  "stateNote": "场景氛围、光线、情绪补充"
}
```

### 正向示例

**剧本原文**：
```
【场景1】外景-南天门垃圾堆-黄昏
黄昏时分，纪凡赛尔蹲在垃圾堆里，手里攥着破扫帚，眼神却亮得吓人。
[对白]
系统：叮——检测到高价值物品，万物回收系统觉醒。
[承上启下]
承接本章开端，纪凡赛尔在南天门垃圾堆发现异常。
```

**正确输出**：
```json
{
  "startFrame": "@纪凡赛尔 蹲在 @南天门垃圾堆 中，枯草般的头发沾满灰尘，手中攥着 @破扫帚，眼神茫然扫视前方，黄昏侧逆光勾勒轮廓",
  "endFrame": "@纪凡赛尔 瞳孔骤然收缩，眼中倒映蓝色光芒，身体僵硬定住，手中扫帚微微颤动，面露震惊之色",
  "prompt": "@纪凡赛尔 蹲在垃圾堆中翻找，突然停住，瞳孔骤缩眼中蓝光闪烁，身体僵硬，系统（机械提示音）：\"叮——检测到高价值物品，万物回收系统觉醒\"，@纪凡赛尔 面露震惊惊喜，手中扫帚微微颤抖，冷风拂过垃圾山，黄昏光线侧照",
  "cameraMovement": "从中景固定镜头开始，缓慢推进至面部特写，捕捉眼中蓝光闪烁瞬间",
  "characterAction": "@纪凡赛尔 翻找动作骤停，瞳孔收缩，眼睛瞪大，嘴微张，身体僵硬，双手微颤，呈现震惊惊喜表情",
  "stateNote": "黄昏外景，垃圾山背景，冷风，侧逆光，紧张发现的氛围"
}
```

### 负向反例

| 反例 | 问题 |
|------|------|
| prompt 中没有对白 | 丢失关键剧情信息 |
| startFrame 与上一镜不衔接 | 破坏连贯性 |
| 字段内容互相矛盾 | 如 startFrame 说角色站着，characterAction 说蹲着 |
| 包含英文或JSON标记 | 格式错误 |
| 角色名未用@标记 | 无法关联资产 |
| 完全脱离剧本原文 | 自由发挥，不可控 |

## 资产引用规则

提及系统已注册的角色、场景、物品时，必须在名字前加 `@` 符号：

- 角色：`@纪凡赛尔`、`@雷公`、`@电母`
- 场景：`@南天门垃圾堆`、`@天庭`
- 物品：`@破扫帚`、`@雷锤`

## 输出自检清单

- [ ] prompt 包含对白（如有），格式为 `角色名："台词"`
- [ ] startFrame 承接上一分镜 endFrame
- [ ] 所有字段纯中文，无英文
- [ ] 角色名、场景名使用@标记
- [ ] 所有描述基于剧本原文
- [ ] cameraMovement 明确运镜起止
- [ ] characterAction 包含对白时的口型/表情
- [ ] JSON 格式合法，无嵌套结构
- [ ] 无水印、无文字、无随机元素
