# 小说章节质检技能

## 核心检查维度

### 1. 🔴 跨章内容重复检测（最高优先级）

#### 检测方法
- 对比上一章结尾300字与本章开头300字
- 检查是否有超过2句话的内容重复（换说法也算）
- 检查是否复述了上一章的完整事件链

#### 问题示例
```
❌ 上一章："陈野在废铁堆发现一块碎片，吞食后感觉身体变化"
❌ 本章开头："陈野在废铁堆发现了一块碎片...（重写发现过程）"
✅ 正确写法："陈野手心还残留着那块碎片的触感，没敢马上动弹"
```

#### 修复策略
- 删除重复内容，只保留状态承接
- 用1-2句过渡带过上章状态
- 立即推进新剧情

---

### 2. 🔴 人物状态一致性检查

#### 检查项
| 维度 | 检查内容 | 常见问题 |
|------|----------|----------|
| 伤情 | 前后伤情是否一致 | 上章"肋骨断裂"，本章突然"左腿渗血"无交代 |
| 位置 | 人物位置是否矛盾 | 上章"陈安在小屋"，本章"陈安不在"无说明 |
| 资源 | 道具/资源是否凭空变化 | 上章获得道具，本章凭空消失 |
| 关系 | 人物关系是否突变 | 无铺垫的敌友转变 |
| 情绪 | 情绪变化是否合理 | 大悲大喜无触发事件 |

#### 修复策略
- 添加交代（如"刚才的搏斗中左腿也被划伤了"）
- 或删除不一致的描述
- 确保所有状态变化都有铺垫

---

### 3. 🔴 战斗完整性检查

#### 检查项
- 战斗是否有明确的开始和结束
- 是否有战斗结果（谁赢了？谁受伤了？）
- 是否有收尾描写（战后状态、情绪、环境）

#### 问题示例
```
❌ "陈野刺向变异鬣狗后戛然而止"
✅ "陈野拼尽全力刺出最后一击，金属刀刃没入鬣狗的甲壳。怪物惨叫一声倒下，四肢痉挛了几下便再也没了动静。陈野瘫坐在地上，大口喘气，手里还握着沾血的刀刃。"
```

#### 修复策略
- 补充战斗结果描写
- 添加战后状态和情绪
- 让战斗自然过渡到下一个场景

---

### 4. 🟡 开头承接检查

#### 正确做法
```
✅ "陈野靠在湿滑的管壁上，胸口还在隐隐作痛"（承接状态）
✅ "夜深了，陈大牛翻来覆去睡不着"（过渡推进）
✅ "手中的铁片泛着微光，陈大牛盯着它看了很久"（细节呼应）
```

#### 错误做法
```
❌ "话说陈野那天在死区遇到了变异鬣狗..."（复述剧情）
❌ "且说上回陈野发现了一块碎片..."（复述剧情）
❌ 重写上一章的完整事件链
```

---

### 5. 🟡 结尾引导检查

- 是否为下一章钩子埋下伏笔
- 是否自然引向下一章的冲突或事件
- 是否有足够的吸引力让读者继续阅读

---

### 6. 🟡 剧情断裂检查

- 是否有无理由的时间跳跃
- 是否有场景跳跃而无过渡
- 是否有因果关系断裂

---

## 质检流程

### 步骤1：逐一检查6个维度
对每个维度进行严格检查，不通过的必须记录具体问题。

### 步骤2：生成修复方案
- 针对每个问题，生成具体的修复方案
- 修复方案必须确保不引入新问题

### 步骤3：输出修复后正文
- 如果需要修复，输出完整的修复后正文
- 修复后的正文必须：
  - 开头不复述上一章内容
  - 所有人物状态前后一致
  - 战斗完整有结果
  - 自然承接上下文

---

## 自检清单

在输出质检结果前，快速自检：

- [ ] 是否检查了跨章重复？
- [ ] 是否检查了人物状态一致性（伤情/位置/资源）？
- [ ] 是否检查了战斗完整性？
- [ ] 是否给出了正确的开头承接方式？
- [ ] 修复后的内容是否还存在问题？
- [ ] 是否提供了具体的修复方案？

如果任一答案为"否"，请补充检查后再输出。
