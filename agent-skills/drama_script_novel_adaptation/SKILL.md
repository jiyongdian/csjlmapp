# 创世纪 · 小说改编剧本专用技能

## 核心理念：小说内容是唯一改编源

**核心原则：剧本必须100%基于小说正文内容进行改编，不得添加小说中没有的情节，不得遗漏小说中的重要内容。**

## 一、小说段落精确映射系统

### 1.1 段落拆分规则

将小说章节正文按以下规则拆分为最小改编单元：

```
拆分优先级：
1. 对话段（有明确角色对白的段落）→ 一个独立场景
2. 动作段（连续的动作描写）→ 一个独立场景
3. 环境转换段（地点/时间变化）→ 新场景开始
4. 心理活动段（角色内心活动）→ 融入相邻场景
```

### 1.2 映射标注格式

每个剧本场景必须精确映射到小说正文的对应段落：

```json
{
  "sceneIndex": 1,
  "sourceBeat": "剧情段3-5",
  "sourceRange": "第3段至第5段",
  "sourceContent": "小说原文摘要...",
  "mappingNotes": "本段对应小说中李明发现秘密纸条并决定调查的情节"
}
```

### 1.3 映射强制规则

1. **每个场景必须有sourceBeat**：标注该场景对应的小说正文段落编号
2. **sourceBeat必须连续**：场景1对应剧情段1-2，场景2对应剧情段3-4，以此类推
3. **不得跳段改编**：禁止跳过小说中的任何重要段落
4. **不得重复改编**：禁止将同一段小说内容重复改编为多个场景
5. **不得遗漏关键内容**：以下内容必须全部覆盖：
   - 所有角色对白
   - 所有关键动作
   - 所有情节转折点
   - 所有情感变化点

## 二、场景连贯性生成规则

### 2.1 场景衔接三要素（强制执行）

每个场景的 `sceneTransition` 必须包含三个具体要素：

```
sceneTransition = {
  "fromPrevious": "具体引用上一场的结尾内容",
  "trigger": "具体说明本场因上一场何事触发",
  "toNext": "具体暗示本场结尾将如何推进下一场"
}
```

**强制要求：**

1. `fromPrevious` 必须引用上一场的**具体内容**：
   - 上一场的最后一个动作
   - 上一场的最后一句对白
   - 上一场结尾的情绪状态
   - 上一场留下的悬念

2. `trigger` 必须说明**具体触发原因**：
   - 不得使用"剧情发展需要"等泛化说法
   - 必须引用上一场的某个具体事件作为触发原因

3. `toNext` 必须暗示**具体走向**：
   - 不得使用"为下一场做铺垫"等套话
   - 必须暗示下一场的具体情节方向

### 2.2 禁止的脱节模式

以下模式**严禁**出现，违者视为生成失败：

| 脱节模式 | 示例 | 正确做法 |
|---------|------|---------|
| 凭空换场景 | 上一场在咖啡馆，下一场突然在医院 | 必须在transition中说明：李明接到电话，得知母亲住院，紧急赶往医院 |
| 凭空换人 | 上一场以李明结束，下一场突然出现王芳 | 必须在transition中说明：李明出门时遇到王芳，两人决定一起去医院 |
| 凭空变状态 | 上一场李明受伤，下一场李明完全康复 | 必须在transition中说明：李明在医院接受了紧急治疗，伤势得到控制但需要休养 |
| 时间跳跃无说明 | 直接从"晚上"跳到"第二天下午" | 必须说明：李明在医院守了一整夜，第二天下午医生通知病情稳定 |
| 地点跳跃无说明 | 从A地点直接跳到B地点 | 必须说明：李明离开公司，打车前往医院途中遇到堵车 |

### 2.3 场景内容要求

每个场景必须包含以下**完整要素**：

1. **场景标识**：
   - `sceneTitle`：格式"内外景-地点-时间"
   - 示例："内景-仁爱医院急诊室-深夜"

2. **环境描述**（description，至少50字）：
   - 具体的视觉细节
   - 灯光、声音、氛围
   - 不得使用"混乱的""神秘的"等模糊形容词

3. **角色动作**（actions，至少30字）：
   - 具体的肢体动作
   - 面部表情
   - 情绪外化表现
   - 不得使用"很生气""很害怕"等直接叙述

4. **角色对白**（dialogues）：
   - 小说原文中的对白必须全部保留
   - 不得省略任何重要对白
   - 对白必须口语化、自然

5. **承上启下**（sceneTransition，至少30字）：
   - 严格遵循三要素格式

## 三、章节连贯性规则

### 3.1 章节开场要求

每章第一个场景必须：

1. **承接上一章结尾**：
   - 明确延续上一章结尾的时间点
   - 展示上一章结尾主要角色的当前状态
   - 从上一章结尾的最后事件自然延伸

2. **禁止的开场方式**：
   - ❌ 禁止直接跳过时间而不做说明
   - ❌ 禁止直接切换到新角色而不引入
   - ❌ 禁止直接改变角色状态而不交代

3. **正确的开场示例**：
   ```
   上一章结尾：李明在咖啡馆发现了一张神秘纸条，上面写着一个地址。
   本章开场：
   场景1：内景-李明的出租屋-深夜
   sceneTransition: "上一场中李明在咖啡馆发现了写着地址的神秘纸条，他立刻离开咖啡馆，打车回到出租屋，准备仔细研究纸条上的内容。本场将展示李明在出租屋中研究纸条，决定第二天去纸条上的地址一探究竟。本场结尾李明收拾东西准备出发，为下一场前往神秘地址做铺垫。"
   ```

### 3.2 章节收尾要求

每章最后一个场景必须：

1. **留下清晰的钩子**：
   - 为下一章设定明确的起始点
   - 制造悬念或期待
   - 不得突然中断正在进行的剧情线

2. **更新角色状态账本**：
   - 记录所有出场角色的当前状态
   - 为下一章的角色状态延续提供依据

3. **禁止的收尾方式**：
   - ❌ 禁止突然中断重要对话
   - ❌ 禁止未解决的冲突无疾而终
   - ❌ 禁止角色状态无交代

### 3.3 跨章一致性检查清单

生成每章时必须自检：

- [ ] 角色名是否与上一章完全一致？
- [ ] 角色外貌描述是否与上一章一致？
- [ ] 角色语言风格是否与上一章一致？
- [ ] 上一章的悬念是否在本章有推进？
- [ ] 上一章的角色状态是否自然延续到本章？
- [ ] 地点/时间线是否与上一章连贯？
- [ ] 上一章出现的物品/线索是否在本章继续存在？
- [ ] 上一章建立的人物关系是否保持一致？

## 四、小说内容覆盖率保证

### 4.1 覆盖率定义

**小说内容覆盖率 = 剧本场景覆盖的小说段落数 / 小说总段落数**

**强制要求：覆盖率必须达到100%，不得遗漏任何重要内容。**

### 4.2 覆盖检查规则

生成完成后必须检查：

1. **段落覆盖检查**：
   - 小说中的每个对话段是否都有对应的剧本场景
   - 小说中的每个动作段是否都有对应的剧本场景
   - 小说中的每个转折点是否都有对应的剧本场景

2. **内容完整性检查**：
   - 所有重要对白是否都已转成dialogues
   - 所有关键动作是否都已转成actions
   - 所有情感变化是否都已通过角色表现呈现

3. **禁止的内容损失**：
   - ❌ 禁止压缩重要对白为概述
   - ❌ 禁止删除关键动作描写
   - ❌ 禁止省略重要的情感铺垫

### 4.3 覆盖率不足时的处理

- **覆盖率 < 80%**：必须重写，确保覆盖所有重要内容
- **覆盖率 80-95%**：需要补充缺失的场景
- **覆盖率 ≥ 95%**：可以接受，但仍需检查遗漏

## 六、质检规则

### 6.1 覆盖率质检

```python
def check_coverage(novel_content, scenes):
    """检查小说内容覆盖率"""
    
    # 提取小说中的关键元素
    novel_dialogues = extract_dialogues(novel_content)
    novel_actions = extract_actions(novel_content)
    novel_events = extract_events(novel_content)
    
    # 提取剧本中的对应元素
    script_dialogues = extract_script_dialogues(scenes)
    script_actions = extract_script_actions(scenes)
    script_events = extract_script_events(scenes)
    
    # 计算覆盖率
    dialogue_coverage = len(script_dialogues) / max(len(novel_dialogues), 1)
    action_coverage = len(script_actions) / max(len(novel_actions), 1)
    event_coverage = len(script_events) / max(len(novel_events), 1)
    
    # 综合覆盖率
    total_coverage = (dialogue_coverage + action_coverage + event_coverage) / 3
    
    return {
        "dialogue_coverage": dialogue_coverage,
        "action_coverage": action_coverage,
        "event_coverage": event_coverage,
        "total_coverage": total_coverage,
        "missing_elements": find_missing_elements(novel_content, scenes)
    }
```

### 6.2 连贯性质检

```python
def check_continuity(scenes):
    """检查场景连贯性"""
    
    issues = []
    
    for i in range(1, len(scenes)):
        prev_scene = scenes[i-1]
        curr_scene = scenes[i]
        
        # 检查transition是否包含三要素
        transition = curr_scene.sceneTransition
        if not has_three_elements(transition):
            issues.append(f"场景{i+1}的transition缺少三要素")
        
        # 检查角色连续性
        if not has_character_continuity(prev_scene, curr_scene):
            issues.append(f"场景{i+1}的角色与上一场脱节")
        
        # 检查地点变化合理性
        if not has_location_transition(prev_scene, curr_scene):
            issues.append(f"场景{i+1}的地点变化缺少说明")
        
        # 检查动作连续性
        if not has_action_continuity(prev_scene, curr_scene):
            issues.append(f"场景{i+1}的动作与上一场断裂")
    
    return issues
```

### 6.3 质检结果处理

| 严重程度 | 问题类型 | 处理方式 |
|---------|---------|---------|
| 🔴 严重 | 覆盖率 < 80% | 必须整章重写 |
| 🔴 严重 | 存在凭空换人/换场景 | 必须整章重写 |
| 🟡 中度 | 覆盖率 80-95% | 补充缺失内容 |
| 🟡 中度 | transition缺少三要素 | 修正transition |
| 🟢 轻微 | transition不够具体 | 标记警告，建议改进 |

## 八、禁止输出内容

以下内容严禁出现在输出中：

- 小说原文的段落标注信息
- 覆盖率检查的元数据
- 质检清单本身
- 任何内部注释或思考过程
- 与剧本无关的结构化数据标记
- Entity、fictional_character等JSON标签
