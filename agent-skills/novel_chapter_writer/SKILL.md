# 小说章节正文

- 长篇网文叙事，非短剧剧本；纯正文，无章节标题行与作者按语。
- 续写时只输出新增段落；一次生成时写完整章。
- 须衔接上一章结尾与全书大纲；人称、时态、人物性格前后一致。
- **15项一致性**：环境、境界、资源、人设、伤势、时间等须对齐前文，禁止无铺垫突变与吃书；详见 `continuity` Skill。
- 全文简体中文，禁止中英夹杂。

## 人写网文（生成时遵守）

1. **段落**：长短自然变化（对话/转折可 1 句成段，叙述常见 2～3 句）；段间空一行；忌诗化碎行，忌每段固定句数。
2. **语气**：对话与叙述适度用语气词（吧、呢、啊、嗯、啧 等）；「……」表迟疑。
3. **画面感**：五感具体；拟声「轰隆——」可独立一行，少量即可。
4. **禁 AI 套话**：值得注意的是、不禁、至关重要等。

## oh-story 增强：情绪交付与模块化写法

正文生成优先交付读者情绪，不只完成剧情摘要：

1. **场景先问情绪**：本场要让读者爽、急、酸、怕、笑、心疼或好奇；无情绪功能的说明性段落应压缩。
2. **模块化兑现**：打脸要有压迫、误判、反证、释放；反转要有误导、证据、揭露、余震；暧昧要有试探、误读、身体/语言细节、未说出口。
3. **钩子类型轮换**：信息钩子、危险钩子、关系钩子、身份钩子、选择钩子，不要每章都用同一种句式。
4. **对标只取节奏**：可学习同类型作品的冲突密度和情绪曲线，但人物、设定、具体桥段必须原创。
5. **少解释，多动作**：用动作、对话、场景反应体现心理；减少总结式评语和作者替读者解释。
6. **章末留力**：章末钩子必须来自具体事件或新信息，不用空泛命运感、哲理句、宏大旁白收尾。

## 武打/斗法章节增强：动作是人物外化

写武侠、玄幻、修真、都市格斗、兵器战、机甲近战时：

- **先写赌注与动机**：这场输了会失去什么，主角为什么必须这样打。
- **空间要清楚**：写清双方距离、朝向、地形、兵器长度、可利用环境，避免读者看不懂站位。
- **招式有节奏**：起势、试探、爆发、化解、反击、高潮、收势，至少形成一个完整小弧线。
- **少堆招名**：招名服务画面与情绪；每个关键招要写发力、目标、化解、结果。
- **把限制写成戏**：伤势、抱人、狭窄空间、不能伤人、兵器断裂等限制要改变打法。
- **后果落地**：喘息、退步、手麻、衣袂碎裂、地面裂痕、灵气紊乱等要承接下一段状态账本。
