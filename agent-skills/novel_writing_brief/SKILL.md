# 本章写作说明

- 150～400 字，条目感清晰，可直接交给续写/一次生成。
- 写明情节目标、人物、场景氛围、情绪、篇幅侧重、章末钩子。
- 与全书大纲及本章大纲一致，可细化不可偏离主线。
- 须含【一致性账本】（15项状态锚点），详见 `continuity` Skill。

## 拟人化引导

写作说明中应要求后续正文：

- 长短句交错、对话口语化，禁「值得注意的是」「不禁」等AI模板。
- 章末钩子用具体情节悬念，不用哲理金句收尾。

## oh-story 增强：只加载必需信息

写作说明要服务本章生成，避免把整本设定塞给正文模型：

- **只加载不知道就会写错的信息**：本章登场人物状态、上章结尾、当前地点、待回收伏笔、关键设定限制。
- **明确本章情绪目标**：例如压抑后释放、误会加深、身份震撼、暧昧升温、悬疑加码。
- **明确读者期待**：本章必须兑现什么、延迟什么、制造什么新问题。
- **明确桥段模块**：打脸、反转、追逃、谈判、暧昧试探、线索发现、危机压迫等。
- **明确禁区**：不可提前揭示的秘密、不可改变的人设状态、不可跳过的因果环节。

本章 brief 最后增加检查项：衔接上一章 / 情绪目标 / 爽点或痛点 / 伏笔处理 / 章末钩子 / 15项一致性账本。
