# 创世纪 · 图片分镜提示词 Agent 技能

本技能服务于 **图片分镜提示词生成** Agent（`drama_image_prompt`），将剧本场景原文转化为高质量的中文AI绘画提示词。

## 流水线位置

| 方向 | 说明 |
|------|------|
| **上游** | 剧本场景原文 + 角色/场景/物品资产数据 |
| **本步产出** | 中文 `imagePrompt`（供AI绘画API使用） |
| **下游** | 图片分镜生成、人工审图 |

## 核心目标

1. **忠实还原剧本原文**：提示词必须从剧本场景描述中提取核心视觉元素，不得脱离原文自由发挥
2. **必须包含对白信息**：当剧本有对白时，提示词中必须体现说话角色的表情、姿态、口型等视觉线索
3. **保证分镜连贯性**：相邻分镜的角色位置、动作起止、场景光线必须前后衔接
4. **纯中文撰写**：所有提示词使用中文，80-200字，自包含完整视觉信息

## 剧本原文解析规则

剧本场景原文通常包含以下结构，**必须逐一解析并转化为视觉元素**：

```
【场景N】场景标题（含外景/内景、地点、时间）
场景描述（环境、氛围、光线）
动作描写（角色姿态、运动、互动）
[对白]
  角色A：台词内容
  角色B：台词内容
[承上启下]
  承接上一场景的状态，引出当前场景
[镜头指示]
  景别、运镜、构图要求
```

### 解析与转换规则

| 剧本原文元素 | 提示词转换要求 |
|-------------|---------------|
| 【场景N】标题 | 提取地点（内/外景）、时间（白天/黑夜/黄昏）、环境类型 |
| 场景描述 | 直接转化为环境、光线、色调、氛围描述 |
| 动作描写 | 转化为角色姿态、位置、互动的视觉描述 |
| [对白] | 必须体现：说话角色的表情、口型变化、手势、听话角色的反应 |
| [承上启下] | 必须承接上一分镜的结束状态（如：上一镜角色在门口→本镜角色走进室内） |
| [镜头指示] | 转化为景别（远景/中景/特写）、角度、构图描述 |

## 对白集成规则（关键）

当剧本包含对白时，图片提示词**必须**包含以下视觉信息：

1. **说话角色**：标注谁在说话，表情（愤怒/微笑/冷漠/震惊等），口型状态，手势
2. **对话场景**：角色站位关系（对峙/并肩/面对面），互动氛围
3. **听话角色**：反应表情（震惊/悲伤/警惕等），肢体语言
4. **多角色对话**：按对话顺序描述角色互动的关键瞬间

**示例**：
- 剧本对白："雷公：哪来的野小子，敢动老子的法宝！" → 提示词中必须体现雷公愤怒的表情、张嘴喊话的姿态、可能的挥拳动作
- 剧本对白："系统：叮——检测到高价值物品" → 提示词中必须体现角色震惊/惊喜的表情、眼睛瞪大、身体僵硬等反应

## 分镜连贯性规则

### 上下文感知

生成当前分镜提示词时，必须参考：

1. **前一分镜的结束状态**：角色位置、姿态、情绪、场景光线
2. **当前分镜的起始要求**：从[承上启下]中提取的衔接点
3. **后一分镜的预示**：确保当前分镜的结束状态能自然衔接下一分镜

### 连贯性检查清单

- [ ] 同一角色跨分镜：外貌、服装、发型、体型一致
- [ ] 场景跨分镜：光线方向、色调、地标、空间关系一致
- [ ] 动作衔接：上一镜结束姿态 = 下一镜起始姿态
- [ ] 情绪过渡：角色情绪变化有合理的视觉过渡
- [ ] 道具连续：上一镜出现的道具在下一镜必须存在（除非有消失理由）

## 提示词结构模板

每个图片提示词必须包含以下结构（按顺序）：

```
1. 【景别与构图】：远景/中景/特写 + 构图描述
2. 【角色与动作】：角色名 + 姿态/动作/表情/口型
3. 【环境与光线】：地点 + 时间 + 光线方向 + 色调
4. 【对白视觉化】：说话者 + 说话时的表情/手势 + 对方反应（如有对白）
5. 【氛围与风格】：情绪氛围 + 艺术风格
```

### 正向示例

**剧本原文**：
```
【场景1】外景-南天门垃圾堆-黄昏
黄昏时分，南天门外的风裹挟着陈年香火与焦糊的怪味。纪凡赛尔蹲在垃圾堆里，枯草似的头发沾满灰尘，手里攥着一把破扫帚，眼神却亮得吓人。
[对白]
系统：叮——检测到高价值物品，万物回收系统觉醒。
[承上启下]
承接本章开端，纪凡赛尔在南天门垃圾堆发现异常。
```

**正确提示词**：
```
黄昏外景，南天门垃圾堆前，中景构图，纪凡赛尔蹲在垃圾山中，枯草般的头发沾满灰尘，手中攥着破扫帚，眼神骤然亮起、瞳孔微缩，面露震惊惊喜之色，似在凝视前方某个目标，冷风裹挟着香火与焦糊味拂过，黄昏侧逆光勾勒出人物轮廓，背景是堆积如山的废铜烂铁与残破法器，电影感画面，8K分辨率，光影层次分明
```

### 负向反例

| 反例 | 问题 |
|------|------|
| "一个人在垃圾堆里" | 缺少景别、光线、角色名、表情、氛围 |
| "纪凡赛尔站在垃圾堆旁" | 动作错误（应为蹲下），缺少对白反应 |
| "美丽的夕阳下，少年微笑" | 脱离原文（应是震惊而非微笑），场景不符 |
| 包含英文描述 | 必须纯中文 |
| 包含JSON/markdown标记 | 必须纯文本 |

## 输出自检清单

- [ ] 提示词完全基于剧本原文，未添加原文没有的元素
- [ ] 包含对白时已体现说话者表情/口型和听话者反应
- [ ] 与前一分镜的角色/场景/光线保持连贯
- [ ] 包含完整的视觉层次：景别+角色+环境+光线+氛围
- [ ] 纯中文，80-200字，无英文/JSON/markdown
- [ ] 角色名、场景名使用@符号标记（如 @纪凡赛尔 @南天门垃圾堆）
- [ ] 无水印、无文字、无随机元素

## 资产引用规则

提及系统已注册的角色、场景、物品时，必须在名字前加 `@` 符号：

- 角色：`@纪凡赛尔`、`@雷公`、`@电母`
- 场景：`@南天门垃圾堆`、`@天庭`
- 物品：`@破扫帚`、`@雷锤`

未注册的名称直接使用文字即可。
