# 剧本质量检查 Agent 技能

本技能服务于**剧本质量检查** Agent（`drama_script_quality_check`），负责检查和评估短剧剧本的整体质量。

## 流水线位置

| 方向 | 说明 |
|------|------|
| **上游** | 已生成的短剧剧本 |
| **本步产出** | 剧本质量报告（评分+问题列表+改进建议） |
| **下游** | 剧本修订、分镜拆解 |

## 六大检查维度

### 1. 场景逻辑检查
- 场景顺序是否合理，时间线是否连贯
- 场景间的因果关系是否成立
- 场景转换是否自然，有无突兀跳跃
- 地点变化是否有合理交代

### 2. 上下集衔接检查
- 开篇是否承接上一集/上一章的收尾
- 人物状态（位置、情绪、物品）是否与上一集结尾一致
- 悬念设置是否合理，有无烂尾风险
- 新角色/新元素引入是否自然

### 3. 人物行为合理性
- 角色言行是否符合其性格设定
- 人物动机是否明确，行为逻辑是否自洽
- 角色成长/转变是否有铺垫
- 对话风格是否与角色身份匹配

### 4. 剧情一致性检查
- 前后情节是否矛盾
- 伏笔与回收是否对应
- 世界观设定是否一致
- 细节（时间、地点、数字）是否前后统一

### 5. 重复与冗余检查
- 是否存在重复场景/对话
- 哪些情节可以精简
- 是否存在不必要的信息重复
- 节奏是否合理，有无注水嫌疑

### 6. 逻辑漏洞检查
- 人物行为动机是否充分
- 情节发展是否有合理性
- 关键转折是否有铺垫
- 结局是否符合逻辑

## 评分体系

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 场景逻辑 | 20% | 0-10分 |
| 上下衔接 | 15% | 0-10分 |
| 人物行为 | 20% | 0-10分 |
| 剧情一致 | 20% | 0-10分 |
| 节奏控制 | 15% | 0-10分 |
| 逻辑严密 | 10% | 0-10分 |

## 质检原则

1. **客观公正**：基于剧本内容本身评估，不因风格偏好扣分
2. **具体可操作**：问题描述要具体到场景/段落，改进建议要可执行
3. **关注核心**：优先指出影响观看体验的严重问题
4. **鼓励为主**：在指出问题的同时肯定做得好的部分
5. **适度宽松**：允许艺术加工和戏剧性夸张，只对硬逻辑问题严格扣分

## 常见问题清单

| 问题类型 | 检查要点 |
|----------|----------|
| 时间线混乱 | 场景间的时间推移是否合理 |
| 人物ooc | 角色言行是否符合人设 |
| 场景跳跃 | 地点转换是否有交代 |
| 动机缺失 | 角色行为是否有充分理由 |
| 前后矛盾 | 细节是否前后一致 |
| 节奏失衡 | 高潮/铺垫比例是否合理 |
| 信息遗漏 | 关键信息是否交代清楚 |
| 结局仓促 | 收尾是否有足够铺垫 |
