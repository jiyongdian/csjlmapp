# 跨集去重 Agent 技能

本技能服务于**剧本生成** Agent（`script-generate-system`），负责在生成新一集剧本时，确保与前序已生成集数的内容差异化。

## 核心原则

### 1. 场景独立性
- 每一集的场景必须承载**独立的、唯一的剧情任务**
- 不得将前一集已完成的场景（地点、动作、对白）在本集中重演
- 即使剧情延续，也必须以新的角度、新的冲突推进呈现

### 2. 对白差异化
- 严禁复制前一集的完整对白或改写后近似复述
- 相同角色在不同集的对话必须体现人物状态的变化和推进
- 禁止出现"上一集说过的话换个说法再说一遍"

### 3. 动作/场景差异化
- 同一地点连续出现时，必须细分微地点或动作阶段
- 动作描写必须体现新的剧情推进，不能只是重复上一集的紧张感
- 场景标题、动作、对白和结尾结果都要明显不同

## 具体规则

### ✅ 必须遵守
1. **阅读前序场景清单**：在生成前仔细阅读提供的前序章节场景清单
2. **标注剧情段进度**：使用 sourceBeat 明确标记当前场景对应的新剧情段
3. **新冲突推进**：每个新场景必须引入新的冲突、新的决定或新的关系变化
4. **人物状态延续但不重复**：承接人物状态，但不重复展现前一集已完成的动作
5. **禁止"原地踏步"**：如果前一集已经完成了"发现→确认→行动"的完整链条，本集必须进入新的链条

### ❌ 绝对禁止
1. 禁止直接复制前一集的场景标题
2. 禁止复述前一集已完整展现的对白内容
3. 禁止将前一集的动作场景换个描述方式重写
4. 禁止在相同地点、相同人物、相同情绪下重复展现相似情节
5. 禁止"第一集做了A→B→C，第二集又做A→B→C"的结构重复

## 差异化策略

### 策略1：推进式差异化
- 前一集完成了"发现神秘物品→尝试使用→确认有效"
- 本集应继续推进到"研究新功能→发现副作用→决定如何处理"
- **关键**：展示人物在新信息下的不同反应和新决定

### 策略2：视角切换
- 前一集以主角视角描写了事件A
- 本集可以切换到配角视角，或从另一个角度补充细节
- **关键**：提供新的信息量，而不是重复已有信息

### 策略3：冲突升级
- 前一集建立了初步冲突
- 本集应将冲突推向新的高度或引入新的阻碍
- **关键**：展示冲突的演变，而不是原地踏步

## 自检清单

在输出剧本前，请自检：

- [ ] 我是否阅读了前序场景清单？
- [ ] 我的每个场景是否引入了新的剧情元素？
- [ ] 我的对白是否没有重复前一集的内容？
- [ ] 我的场景标题是否与前一集有明确区分？
- [ ] 我的sourceBeat是否标记了新的剧情段？
- [ ] 我的场景是否推进了故事，而不是原地踏步？

如果以上任一问题答案为"否"，请修改后再输出。
