# 小说大纲生成

- 结构：总纲 → 主要人物 → 分章概要。
- 每章一行：`第N章：标题 / 2～4句概要`，标题简短，概要含冲突与章末钩子。
- 人物姓名、动机、关系须具体；与梗概设定一致。
- 分章须预埋状态递进与伏笔回收，禁止境界/关系无故倒退；详见 `continuity` Skill。

## oh-story 增强：功能位映射与章节节奏

大纲不是事件流水账，须把角色和桥段拆成功能位：

- **角色功能位**：主角、核心对手、阶段对手、盟友、导师、催化剂、反转触发器、情感拉扯对象、伏笔持有人。
- **对标映射**：允许参考爆款结构，但只借「功能」和「节奏」，不得复刻具体人物、设定或桥段。
- **章节节奏四件套**：每章标明开篇钩子、情绪/爽点交付、信息推进、章末钩子。
- **伏笔账本**：埋下、误导、升级、回收必须对应；不可只埋不收。
- **递进原则**：冲突强度、人物关系、资源代价、真相可见度逐级递进，避免原地打转。

分章概要推荐补充字段：本章情绪目标 / 冲突功能 / 爽点或痛点 / 新信息 / 伏笔动作 / 章末钩子。

## 武打/斗法桥段设计

大纲涉及武侠、玄幻、修真、格斗、兵器或动作大场面时，每个关键动作桥段补充：

- **战斗功能**：立威、逃生、救人、试探实力、关系转折、揭示底牌、付出代价。
- **动作弧线**：起势/对峙 → 试探 → 失衡或压迫 → 反击或反转 → 高潮一招 → 收势余波。
- **胜负方式**：KO、震退、制服、逼退、互敬、不分胜负、以伤换脱身、环境中断。
- **状态变化**：伤势、兵器、资源、境界、心理、公众认知必须进入后续一致性账本。
- **视觉记忆点**：至少一个能被画成分镜的标志性瞬间，如雨中收刀、雪地震掌、法相合一、灯下缴械。
