# 创世纪 · 自然派剧本生成技能

## 核心原则

**像写优秀短剧一样写剧本：简洁、连贯、有力量。**

## 一、剧本格式规范（必须严格遵循）

### 1.1 场景标题格式
```
N-M 时间/内或外/地点 人物：角色A、角色B
```
- N：集数编号
- M：本集场景序号
- 时间：清晨、日、夜、傍晚等
- 内或外：内（室内）或外（室外）
- 地点：具体场景地点
- 人物：本场景出现的所有角色

### 1.2 内容格式
```
△动作描写（用△符号开头，描述场景中的动作、环境、表情）
角色名：对白内容
角色名（表情/动作）：带表情提示的对白
```

### 1.3 示例（参考剧本风格）

```
第一集
1-1 清晨/内/刘桂兰家 人物：刘桂兰、刘建国、刘建军、刘建伟、广播声
△暴雨下了一整夜。院里的积水刚没过脚面，村口喇叭突然响起。
广播声：上游水位暴涨！低洼住户马上撤离，不要回屋搬东西！
△刘桂兰右腿缠着纱布，坐在二楼楼梯口。她昨晚摔伤了腿，已经打电话叫三个儿子来背她。
△大门被推开，刘建国、刘建军和刘建伟穿着雨衣冲进来。
刘桂兰：先背我去村小学，药和身份证都在我身上。
△刘建国没有上楼，反而直奔一楼卧室。
刘建国：妈，那张六十八万的定期存折呢？
```

## 二、连贯性核心规则

### 2.1 场景衔接（自然衔接，不需要显式过渡文本）

**关键：上一场的最后一个动作/事件，直接成为下一场的触发条件。**

```
正确示例：
- 1-1结尾：△三个人互看一眼，竟同时冲进卧室翻找。
- 1-2开头：1-2 清晨/内/刘桂兰家一楼 人物：...
           △十分钟后，浑黄的水猛地涌进堂屋...

错误示例（显式过渡）：
- 1-1结尾后写："本场结束，为下一场做铺垫..."
- 不要写任何过渡说明
```

### 2.2 角色状态一致性

- 角色外貌、服装、情绪必须前后一致
- 角色位置变化必须通过动作体现（如：△陈春梅冲上楼）
- 角色对话风格必须保持统一

### 2.3 时间线推进

- 场景间时间必须线性推进
- 时间跳跃必须用△描写体现（如：△半小时后）
- 禁止时间倒流或无说明的时间跳跃

## 三、内容完整性规则

### 3.1 小说内容覆盖率

- 必须覆盖小说章节的所有重要内容
- 小说中的对白必须全部转成剧本对白
- 小说中的关键动作必须转成△动作描写
- 小说中的情感变化必须通过角色表现呈现

### 3.2 场景数量

- 根据小说内容长度合理分配场景数量
- 每个场景对应小说的1-3段内容
- 场景数量以完整覆盖内容为准，不设固定数量

### 3.3 禁止的内容缺失

- ❌ 禁止压缩小说对白为叙述
- ❌ 禁止删除小说的关键情节
- ❌ 禁止省略角色的重要情感变化
- ❌ 禁止跳过小说的重要转折点

## 四、对白写作规则

### 4.1 对白必须口语化

```
正确：刘建国：妈，那张六十八万的定期存折呢？
错误：刘建国：母亲，我想询问您那张六十八万元的定期存折放在哪里了？
```

### 4.2 对白必须推动剧情

- 每句对白必须推进剧情、揭示性格或制造冲突
- 禁止无意义的对话填充
- 对白要符合角色身份和性格

### 4.3 表情/动作提示

```
角色名（拍着楼梯扶手）：对白内容
角色名（头也不抬）：对白内容
角色名（怒吼）：对白内容
```

## 五、动作描写规则

### 5.1 动作必须可视化

```
正确：△刘建国趴在床底摸索，刘建军翻柜子找房本，刘建伟抡起铁锤砸一只生锈的铁箱。
错误：△三兄弟在到处找东西。
```

### 5.2 动作必须体现情绪

```
正确：△铁锤一下下砸在锁上。二楼的刘桂兰看着三个儿子的背影，脸色一点点白了。
错误：△刘桂兰很伤心。
```

### 5.3 环境描写

- 用环境烘托气氛
- 环境描写要简洁有力
- 禁止冗余的环境描写

## 六、质量检查清单

在提交剧本前，逐项检查：

1. [ ] 格式是否正确？（场景编号+标题+△+对白）
2. [ ] 场景衔接是否自然？（上一场结尾→下一场开头）
3. [ ] 角色状态是否前后一致？
4. [ ] 是否覆盖了小说的所有重要内容？
5. [ ] 对白是否口语化？
6. [ ] 动作描写是否可视化？
7. [ ] 时间线是否线性推进？
8. [ ] 是否存在冗余内容？
9. [ ] 是否符合人物性格？
10. [ ] 是否有足够的冲突和张力？

## 七、禁止输出内容

以下内容严禁出现：

- sceneTransition、sourceBeat等元数据字段
- 角色状态账本、锚点等内部术语
- 任何JSON格式或代码块标记
- 质检清单本身
- "本场承接上一场"等过渡说明
- "为下一场做铺垫"等预测性文本
- Entity、fictional_character等标签
- 任何对格式的解释性文字

## 八、核心创作理念

### 8.1 让故事自己流动

不要用框架约束故事，让故事自然流动。

### 8.2 用画面讲故事

所有内容都要转化为画面：动作、表情、环境。

### 8.3 用对白推动剧情

每句对白都要有目的：推进剧情、揭示性格、制造冲突。

### 8.4 保持简洁有力

像优秀短剧一样：简洁、有力、不啰嗦。
