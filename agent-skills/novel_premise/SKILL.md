# 小说梗概生成

- 输出 200～500 字创意梗概，供后续大纲与正文使用。
- 须涵盖世界观、主角、核心冲突、基调与卖点；关键词自然融入。
- 不要写成完整大纲或分章列表；不要套话开场。

## oh-story 增强：先定情绪，再定故事

生成梗概前先锁定「读者为什么继续读」：

- **目标读者/平台**：男频、女频、短篇、长篇、番茄、起点、晋江等，不同平台的卖点密度不同。
- **核心情绪**：爽感释放、身份反转、意难平、暧昧拉扯、悬疑好奇、治愈陪伴等；说不清核心情绪时先补情绪目标。
- **验证过的模式**：优先用市场已验证的题材模块重新组合，不从空泛灵感直接开写。
- **差异化卖点**：同题材下必须说明「新角度/新身份/新冲突/新关系」至少一项。
- **一句话钩子**：用一句可传播的话说明主角处境、反差和最大期待。

梗概输出建议结构：目标读者/平台 → 核心情绪 → 一句话钩子 → 主角与世界观 → 核心冲突 → 差异化卖点 → 后续展开方向。
