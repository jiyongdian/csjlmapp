# 武打动作指导

目标：把一句动作戏需求拆成可执行的动作节拍、分镜、N 宫格海报 prompt 或图生视频 prompt。服务短剧分镜、小说动作桥段、武侠/玄幻/修真/格斗/机甲动作视觉化。

## 工作流

1. **收集锚点**：人物、武术/格斗体系、兵器、场景、调性、宫格规格、视频模型、是否参考已有桥段。
2. **先定戏剧功能**：这场打斗解决什么问题：立威、救人、逃生、试探、复仇、揭示底牌、关系转折。
3. **编动作弧线**：起势/对峙 → 试探 → 爆发 → 化解/反击 → 缠斗/转场 → 高潮 → 收势/余波。
4. **拆 key pose 或镜头**：每格/每镜必须有不同重心、朝向、发力部位、景别或空间关系。
5. **输出 prompt**：按用户需要输出中文动作设计、短剧分镜字段建议、英文宫格 prompt、图生视频 prompt 或小说桥段建议。
6. **自检**：清晰、空间、赌注、动机、编排、脆弱、后果都成立后再交付。

## 动作戏 7 原则

- **Clarity 清晰**：谁打谁、用什么、目标哪里、结果如何必须可读。
- **Geography 空间方位**：A/B 左右、距离、朝向、武器长度、地形障碍要连续。
- **Stakes 赌注**：输了会失去什么，赢了会改变什么。
- **Motivation 动机**：每一招来自人物目标，不为炫技而炫技。
- **Choreography 编排**：招式有变化、有逻辑、有节奏，不重复同类姿态。
- **Vulnerability 脆弱**：角色会失衡、受限、喘息、被逼入险境。
- **Consequences 后果**：每一击有可见代价，并影响后续状态。

## 常用体系提示

- **传统武术**：咏春重中线与贴身连消带打；八极重震脚、肘靠、爆发；太极重圆弧、听劲、以柔克刚；少林长拳重大开大合与腾空。
- **现代格斗**：拳击重步法与组合拳；泰拳重肘膝腿与抱缠；MMA 重站立到摔投再到地面控制；BJJ 重地面缠斗与降服。
- **兵器**：刀写弧线和劈砍，剑写点刺撩云，棍写扫拨戳挑，枪写直线扎刺，双截棍写抡甩和接棍。
- **修真/玄幻**：本体动作、法相/灵气方向、环境反应三层同步；不要只写“灵气爆发”。
- **机甲动作**：重量、关节、推进器、装甲碰撞、武器模块切换要清楚。

## N 宫格动作海报要求

- 默认 16 格 4×4；也可 4、9、12 格。
- 每格是同一场动作的连续 key pose，panel order is time order, left to right, top to bottom。
- 保持同一角色、服装、武器、场景光线；禁止跨格变脸、变装、换武器。
- 每格写动作中瞬间：挥到半途、刚要命中、转身化解、落地前一瞬。
- 必须包含姿态变化：低桩、腾空/高位、转身/背身、近景特写，不要全是站桩。
- 若用于图生视频，说明编号、箭头、轨迹线、格子边框是 storyboard annotations，不应出现在最终视频画面。

## 图生视频 prompt 要求

视频 prompt 要告诉模型：参考图是动作分镜表，不是拼贴插画；格序就是时间序；视频应按格序连贯演完，不增删人物、武器、场景，不渲染格子边框、编号、文字和箭头。节奏用相对词：起势稍慢，中段紧凑，高潮拉长，收势留白；不要把所有格写成固定秒数。

## 合规与原创

- 不复刻具体 IP 角色、明星脸、电影桥段的独创表达；只借通用动作类型、节奏和镜头语言。
- 避免血腥、致命命中、窒息、虐杀等直白描述；改用震退、缴械、压制、火花飞溅、重心崩溃、灵气震散。
- 参考已有桥段时，以用户描述为准；不凭记忆硬还原。
