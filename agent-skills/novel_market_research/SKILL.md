# 小说市场扫榜与选题验证

目标：基于平台榜单、用户提供样本或已有资料，识别可执行的题材机会，而不是只复述排名。

## 使用场景

- 用户问「现在什么题材火」「帮我选题」「起点/番茄/晋江榜单怎么看」。
- 用户提供榜单截图、作品列表、链接、书名，要求提炼趋势。
- 开书前需要验证目标读者、平台、题材边界和差异化卖点。

## 方法

1. **先确认平台和方向**：平台、频道、题材、目标篇幅、用户素材储备。
2. **看重复模式，不看单本神话**：至少提取多个样本中的共同书名词、开篇卖点、主角身份、冲突类型、情绪承诺。
3. **区分平台逻辑**：流量平台重完读和强钩子，付费平台重追读、人物成长与长期付费期待，女性向平台重关系张力和人设承诺。
4. **输出可写方向**：每个方向必须说明核心情绪、读者期待、风险、差异化切口、三章验证动作。
5. **不编造数据**：没有真实榜单或用户样本时，只能输出假设与验证方案，不能假装已扫榜。

## 输出格式

- 数据来源/样本边界
- 重复出现的题材模式
- 读者情绪需求
- 可写选题候选（3～5 个）
- 风险与避坑
- 推荐开篇验证方案
