# ComfyUIAI 工作流插件目录

## 目录结构

- `workflows/` - 工作流插件文件（.json 格式）
- `references/` - 参考素材（图片/音频）
- `config.json` - 服务器配置（可选）

## 使用说明

1. 在"视频分镜"页面选择 ComfyUI 模式
2. 点击"点击上传工作流插件"按钮
3. 上传 `.json` 格式的 ComfyUI 工作流文件
4. 选择已安装的工作流插件即可使用

## 支持的工作流类型

- MiniMax H3 视频生成
- 图生视频
- 文生视频
- 音频驱动视频
- 多参考图融合

## 文件命名规则

文件名格式：`工作流名称_时间戳.json`

示例：`MiniMax_H3_全能参考工作流_1787337726896.json`
